What these statuses mean

Working means a usable response was returned for the latest request. Empty means the request worked but returned no games, props or reported absences. Neither verifies every matchup or confirms a healthy starting lineup.

Source/check time comes from the returned data when available; for multiple markets or reports, the oldest timestamp is shown. Last successful response can include cached data. Unknown source time is never replaced with the current time.

Stale means the source/check time, or last response when that is unknown, exceeded the monitoring window. Failed means a request failed; unavailable means the response reported missing coverage. Loading means a background build is unfinished; it is not a successful update. Unchecked means no observation has been recorded. Saved status retains original timestamps across server restarts when persistent storage is available. Background line tracking has its own status above.
