# NFL player production ratings, first version

The optional Build NFL player ratings button loads the league schedule, seasonal rosters for all 32 teams, and player box scores for completed regular-season games strictly before the selected kickoff. It shares an in-memory job by season/cutoff and caches rosters for one hour and completed boxes for one day. Partial schedules, pagination, provider errors, empty rosters and missing team box scores withhold the league build. A new deployment clears these caches. Provider completeness beyond these checks remains unverified.

Each supported position has a set of box-score production metrics. QB: passing yards, passer rating, TDs and interceptions (lower is better). RB: rushing yards, average, TDs and receiving yards. WR/TE: receiving yards, receptions, average and TDs, compared separately. DL: sacks, QB hits, tackles for loss and tackles. LB: tackles, tackles for loss, sacks and passes defended. DB: passes defended, tackles, forced fumbles and interceptions. K: field-goal percentage and points. P: average, punts inside the 20 and touchbacks (lower is better). FB uses rushing/receiving yards when sufficient peers exist. Blocking, detailed coverage, long-snapping and return-only grades are unsupported. Unsupported and insufficient-data players display Unrated, including roster players with no recorded statistics.

For each metric, use the shared season/form blend (50% season average, 50% exponential recent form; three recorded-game half-life). Compare against eligible same-position league roster players with at least two numeric recorded games. Require eight peers per metric and two qualifying metrics per player. The percentile uses half credit for ties and is scaled to 0–99. Smooth each component toward 49.5 using four neutral pseudo-games, then average qualifying components. Display the rounded result, recorded sample and trend. Trend is the mean signed relative change between form baseline and season average, with a +/-3% steady band. All weights, cutoffs and smoothing are experimental assumptions.

These are relative recorded-production ratings, not Madden talent ratings, scouting grades or calibrated win probabilities. Metrics differ in coverage; missing records are not filled with zero. Raw production is affected by opportunity, scheme and game context. Rosters do not verify starters or trades; traded players' team histories remain separate. No opponent-strength correction, snap-adjusted efficiency, lineup replacement valuation or backtesting is included yet. Defensive ratings cannot measure avoided targets or unrecorded coverage work.

Ratings refresh when a build includes new games. They do not yet change team scores or automatic injury values. Existing offensive props independently use the same season/form blend, so the rating is not applied again as an arbitrary multiplier. Live full-league build coverage, API quota and browser rendering still require verification. The button is optional because the first build requires 32 roster requests plus one request per completed game.
