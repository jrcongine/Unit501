# Automatic quarterback and betting-split scenarios

QB estimates are on with Auto injuries for NFL and college. A fresh, matched official Out report and roster are required. The current starter must have at least 15 passing attempts in the latest team game and at least two of the last three, with at least 60% of the latest team's attempts. This avoids repeatedly subtracting for a long-absent QB.

Replacement selection uses a reviewed starter announcement, unique eligible next QB on the published depth chart, or (without depth data) one uniquely experienced eligible backup. That last case is explicitly an estimate, not an announced starter. Conditional/exempt/inactive players and ambiguous replacements are excluded. Existing official college report coverage remains SEC/ACC/Big Ten; unsupported reports are not inferred.

Up to eight completed current-season team games provide passing histories. Require starter 40+ attempts across 2+ games and backup 20+ across 2+. Shrink backup yards/attempt toward the starter's rate with 50 pseudo-attempts. Multiply the difference by the starter's recent attempts; cap yard change at +/-100. Convert using half the team's points/total-offensive-yards rate, capped at +/-4 points. This is an uncalibrated passing-only scenario: rushing style, sacks and interception value are not separately estimated. Missing stats retain the baseline. A passing/receiving lineup scenario suppresses the automatic QB adjustment to avoid duplicate passing effects.

Public & money uses only the unauthenticated VSiN public preview, with DraftKings attribution and an explicit limited-coverage message. No paywall workaround or premium endpoint is used. Match league, team pair and Eastern game date. Preserve bets and handle separately. Fetch time is not source update time: the current public preview does not expose source time, so it is display-only. Source failures never turn into zero percentages.

Users can enter sportsbook/source, exact away spread, away bet/money percentages and source update time. Entries expire after five minutes locally and require source time within 30 minutes, same matchup and exact current spread. The optional experimental adjustment favors the majority-money side only when its money-minus-bet share is at least 10 percentage points. Margin shift = sign(homeMoney-homeBets) * min(0.5,(abs(gap)-5)/100). Transfer half that margin between teams, preserving total. No moneyline signal is added again, and totals/player props are unchanged. This is a sensitivity assumption, not validated sharp-money detection or a fitted edge.

QB and market changes disable reuse of unadjusted probability/error calibration. Forecast archives retain inputs and source metadata; injury baselines remove QB changes while retaining the same market scenario.

Validation: targeted unit/integration tests cover source parsing, scope/freshness, wrong-line withholding, backup production and ambiguity, double-count prevention, signed score changes and archive behavior. Both public league preview URLs were reachable. Browser rendering could not be checked locally because the installed Playwright package has no browser binary.
